 Bento Grid UI
Welcome to the BentoStyleImages component for a modern, visually stunning image showcase layout built with React.js and Tailwind CSS. This page acts as a vibrant landing section, designed to captivate users and convey the essence of the entertainment and casting world.

🚀 Features
⚡ Responsive Bento Grid: A beautifully animated, responsive grid layout using CSS Grid and Tailwind utility classes.

🧠 React + Tailwind Integration: Built with clean React components and modern TailwindCSS for styling.

🎭 Dynamic Hero Section: Features a bold headline, supporting text, and a prominent call-to-action button to guide users to the login/signup.

🎥 Cinematic Image Showcase: Perfect for highlighting casting shoots, director views, and on-set environments.

🎨 Smooth Hover Effects: Subtle zoom and transition animations to enhance interactivity.

🛠️ Tech Stack
React.js

Tailwind CSS

React Router DOM (for navigation)

🖼️ Images Used
All image assets are sourced locally (public/Images/) and should be replaced with your own images or optimized CDN-hosted assets for production.
